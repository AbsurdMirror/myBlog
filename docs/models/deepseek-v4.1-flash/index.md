## 共用符号

| 记号 | 含义 |
|---|---|
| `B` | batch，独立会话数 |
| `S` | 本次处理的 token 数 |
| `S_his` | 参与评分的 KV 总长度，包含本次已加入的 token |
| `B*S` | 逐 token 独立运算时展平的行数，不表示跨会话混合 |
| `hidden` / `D` | 隐藏维度；Layer 0 正文取 `D=5120` |

完整序列示例明确 `S_his=S`；带历史缓存的场景另行声明。可学习权重、运行时系数和固定常数分别说明。
