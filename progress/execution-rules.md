# 上传和发布的执行规则

- 仓库授权、当前可调用工具、真实提交结果分别核验，不以工具搜索空结果推断用户未授权。
- 正式文件使用程序读取原始字节，通过二进制或 Base64 接口传输；禁止手工抄写图片 Base64 或修改图片降低传输量。
- create_blob 只创建对象；只有进入 tree、commit 并更新目标 ref，才算文件入库。用 Git blob SHA 和 SHA256 核对原图。
- main 的文稿、五张 PNG、构建产物、线上页面分别验收。不用旧首页或预期 URL 冒充新站。
- 已获得用户对本项目提交、合并和发布的授权。不重复建测试图片、不反复询问相同授权。
- 保留备份分支和旧站 archive；不重写 Git 历史，不提交密钥、私人笔记或完整聊天记录。
- 本文件属于本地待提交内容；实际远端进度见发布结果，不能用文件中的计划代替部署结果。
