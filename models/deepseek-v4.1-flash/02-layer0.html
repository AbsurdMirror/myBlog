Layer 0：从四路残差到局部注意力与 MoE

1. Layer 0 总览

本文分析 DeepSeek-V4.1-Flash 的 Layer 0 文本前向路径，张量形状按完整逻辑维度表示。

BB 表示 batch，SS 表示本次处理的 token 数，BxS=B×S\mathrm{BxS}=B\times S 表示合并后的 token 维。Attention 仍按各自会话计算。

Layer 0 先计算 Attention，再计算 MoE；两个子层各有独立的一套 mHC。初始四路来自同一份 embedding，整体形状为 [BxS,4,5120]，首次 pre 为 [1,0,0,0]。

每个子层的流程为：

  • 入口汇聚：四路残差汇成一路，同时由四路输入生成混合系数。
  • 子层计算：单路输入 [BxS,5120] 经过 RMSNorm，再执行 Attention 或 MoE。
  • 出口融合：子层输出与保留的原四路残差融合，恢复为 [BxS,4,5120]，交给下一子层。

混合系数生成分支读取当前子层的四路输入。生成的 post、comb 用于当前出口，pre 用于下一子层入口：Attention 侧的 pre 交给本层 MoE，MoE 侧的 pre 交给下一层 Attention。

2. mHC

2.1 四路输入生成 raw mixes

四路输入经过展平、RMS 缩放与联合投影，生成混合系数的原始值。以下 tt 为展平后的 token 索引，dd 为特征元素索引，⊙\odot 表示逐元素相乘；线性权重按 [输出,输入] 排列。

计算分为三步：

  • 展平：X0X_0～X3X_3 沿 hidden 维拼接，每个 token 的 4×51204\times5120 个元素组成 XX [BxS,20480][\mathrm{BxS},20480]。

    X=[X0X1X2X3] X=[X_0\;X_1\;X_2\;X_3]

  • RMS 缩放：对每行的 2048020480 个元素计算一个缩放因子，得到 rr [BxS,1][\mathrm{BxS},1]；这里没有可学习的缩放权重。

    rt=(120480∑d=020479Xt,d2+ϵnorm)−1/2,ϵnorm=10−20 r_t=\left(\frac{1}{20480}\sum_{d=0}^{20479}X_{t,d}^{2} +\epsilon_{\mathrm{norm}}\right)^{-1/2}, \qquad \epsilon_{\mathrm{norm}}=10^{-20}

  • 联合投影：XX 与权重 WW [24,20480][24,20480] 相乘，再按行乘 rr，得到 MM [BxS,24][\mathrm{BxS},24]。

    M=(XW𝖳)⊙r M=(XW^{\mathsf T})\odot r

MM 按 4+4+164+4+16 拆成 MpreM_{\mathrm{pre}}、MpostM_{\mathrm{post}}、McombM_{\mathrm{comb}}，供下一步生成 pre\mathrm{pre}、post\mathrm{post}、comb\mathrm{comb}；它们此时还是原始值。

M=[MpreMpostMcomb] M=[M_{\mathrm{pre}}\;M_{\mathrm{post}}\;M_{\mathrm{comb}}]

XX 提供投影内容，rr 按行广播，对投影结果逐行缩放。

2.2 生成 pre、post、comb

MM 以及由它生成的 pre、post、comb 都是随输入变化的动态值。下面的 ss、bb 是训练得到的模型参数，对所有 token 共用；固定常数由算法给定。

Sinkhorn

Sinkhorn 是行、列交替归一化的迭代方法，使正值矩阵的行和、列和接近 11。在残差混合中，行对应旧残差流，列对应新残差流，分别约束每路分配出去和接收进来的混合系数总量。

对每个 token 的 4×44\times4 工作矩阵 AA，行、列归一化分别为：

RowNorm(A)ij=Aij∑k=03Aik+cColNorm(A)ij=Aij∑k=03Akj+c \begin{aligned} \operatorname{RowNorm}(A)_{ij} &=\frac{A_{ij}}{\sum_{k=0}^{3}A_{ik}+c}\\ \operatorname{ColNorm}(A)_{ij} &=\frac{A_{ij}}{\sum_{k=0}^{3}A_{kj}+c} \end{aligned}

其中，一次 Sinkhorn 迭代表示：

Sinkhorn(A)=ColNorm(RowNorm(A)) \operatorname{Sinkhorn}(A) =\operatorname{ColNorm}\left(\operatorname{RowNorm}(A)\right)

生成 comb

先得到 C0:[BxS,16]C_0:[\mathrm{BxS},16]：

C0=Mcomb⋅s2+bcomb C_0=M_{\mathrm{comb}}\cdot s_2+b_{\mathrm{comb}}

将 C0C_0 重排为 [BxS,4,4][\mathrm{BxS},4,4]。本配置 hc_sinkhorn_iters=20\mathrm{hc\_sinkhorn\_iters}=20：先做行 Softmax、逐项加 cc 和首次列归一化，再执行 1919 次 Sinkhorn 迭代，共完成 2020 次列归一化：

comb=Sinkhorn19(ColNorm(Softmaxrow(C0)+c)) \mathrm{comb}= \operatorname{Sinkhorn}^{19} \left( \operatorname{ColNorm} \left( \operatorname{Softmax}_{\mathrm{row}}(C_0)+c \right) \right)

最终输出 comb:[BxS,4,4]\mathrm{comb}:[\mathrm{BxS},4,4]。

RMSNorm 接收四路汇聚得到的单路输入 ZZ，输出 UU，两者形状均为 [BxS,5120]。γ:[5120]\gamma:[5120] 是可学习权重，没有加法偏置；每个 token 沿 51205120 维独立归一化：

4.2 SWA mask、attention sink 与在线 softmax

固定会话 bb、Query 头 hh 和 Query 位置 ii。令当前内核实际遍历的候选数为 KidxK_{\mathrm{idx}}；prefill 时 Kidx=min(S,128)K_{\mathrm{idx}}=\min(S,128)，decode 时为 128128。对候选 KV 位置 jj，原始得分为：

Eb,h,i,j=Qb,i,hCb,jT512 E_{b,h,i,j}=\frac{Q_{b,i,h}C_{b,j}^{T}}{\sqrt{512}}

pb,iQp^Q_{b,i} 与 pb,jKVp^{KV}_{b,j} 分别表示 Query 和 KV 的绝对位置。128-token 因果滑窗的 mask 为：

Mb,i,j={0,0≤pb,iQ−pb,jKV<128−∞,其他,Zattn=E+M M_{b,i,j}= \begin{cases} 0,&0\le p^Q_{b,i}-p^{KV}_{b,j}<128\\ -\infty,&\text{其他} \end{cases},\qquad Z^{\mathrm{attn}}=E+M

因此每个 Query 只访问自身及此前最多 127127 个位置；在完整序列示意中，就是主对角线及其下方 127 条对角线。

每个头还有一个可学习 sink logit aha_h。它只进入 softmax 分母，不携带 value 内容。直接形式为：

Pb,h,i,j=exp(Zb,h,i,jattn)exp(ah)+∑kexp(Zb,h,i,kattn) P_{b,h,i,j}= \frac{\exp(Z^{\mathrm{attn}}_{b,h,i,j})} {\exp(a_h)+\sum_k\exp(Z^{\mathrm{attn}}_{b,h,i,k})}

mb,h,i=max(ah,maxkZb,h,i,kattn) m_{b,h,i}=\max\!\left(a_h,\max_k Z^{\mathrm{attn}}_{b,h,i,k}\right)

O′b,i,h=∑jPb,h,i,jCb,j O'_{b,i,h}=\sum_j P_{b,h,i,j}C_{b,j}
