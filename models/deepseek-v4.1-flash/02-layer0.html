Layer 0：从四路残差到局部注意力与 MoE

第 0 层可以先看成两个串行子层：局部 Attention（SWA）与 MoE 前馈网络。它们之间传递的不是一条隐藏向量，而是四路残差流；mHC 负责将四路汇聚成一路供子层计算，再把结果融合回四路。配置 · Block 定义

本文以已经讨论过的数学关系为主线，配合五张采用版原图。图中的已知歧义在相邻文字中注明，未擅自重画。量化存储、kernel 调度与性能估算放在后续文章。

1. 先固定符号与输入输出

B*S 逐 token 独立计算时展平的行数，不表示合并会话
D=5120 每路隐藏维度
H=4 mHC 残差流数，不是注意力头数

四路残差在入口分出旁路，一直保留到该子层出口。MoE 的“原四路”是 Attention 融合后的结果，不是整层最初的输入。第 0 层没有全局 KV 分支与 Engram；其他层的差异另文处理。

3. mHC：系数生成、汇聚与残差融合

3.1 系数生成前半段：四路 X → raw mixes M

图 2 · 每个 token 的四路共 20480 个元素参与一个归一化统计，再投影成 24 个 raw 值。公式中的投影仍然读取展平后的 X，不能只把 r 作为输入。

将 X:[B*S,4,5120]X:[B*S,4,5120] 展平为 Xf:[B*S,20480]X_f:[B*S,20480]。对 token tt：

rt=(120480∑d=020479Xf,t,d2+ϵnorm)−1/2 r_t=\left(\frac{1}{20480}\sum_{d=0}^{20479}X_{f,t,d}^2+\epsilon_{\mathrm{norm}}\right)^{-1/2}

M=(XfWHCT)⊙r M=(X_fW_{\mathrm{HC}}^T)\odot r

对象 shape 性质
rr [B*S,1] 当前输入算出的缩放因子，沿 24 维广播
WHCW_{\mathrm{HC}} / hc_fn [24,20480] 可学习投影
MM / mixes [B*S,24] 运行时 raw mixes
ϵnorm\epsilon_{\mathrm{norm}} 标量，10−2010^{-20} 固定常数

这里没有独立的可学习 RMSNorm 缩放向量。MM 按最后一维分为 Mpre:[B*S,4]M_{\mathrm{pre}}:[B*S,4]、Mpost:[B*S,4]M_{\mathrm{post}}:[B*S,4] 和 Mcomb:[B*S,16]M_{\mathrm{comb}}:[B*S,16]。

3.2 系数生成后半段：M → pre / post / comb

图 3 · hc_scale 的三个标量分别作用于三组 raw mixes；hc_base 按 4＋4＋16 拆分。每个 token 最终获得两个 4 维向量和一个 4×4 矩阵。

定义可学习参数：s=[s0,s1,s2]:[3]s=[s_0,s_1,s_2]:[3]，bpre:[4]b_{\mathrm{pre}}:[4]、bpost:[4]b_{\mathrm{post}}:[4]、bcomb:[16]b_{\mathrm{comb}}:[16]。计算：

pre=σ(s0Mpre+bpre)+ϵhc pre=\sigma(s_0M_{\mathrm{pre}}+b_{\mathrm{pre}})+\epsilon_{\mathrm{hc}}

post=2σ(s1Mpost+bpost) post=2\sigma(s_1M_{\mathrm{post}}+b_{\mathrm{post}})

C0=reshape4×4(s2Mcomb+bcomb) C_0=\operatorname{reshape}_{4\times4}(s_2M_{\mathrm{comb}}+b_{\mathrm{comb}})

其中 σ(x)=1/(1+e−x)\sigma(x)=1/(1+e^{-x})，ϵhc=10−6\epsilon_{\mathrm{hc}}=10^{-6}。最终 pre、post 均为 [B*S,4]；C0C_0 为 [B*S,4,4]，尚不是最终 comb。

comb 的 20 轮究竟怎么算？ 对每个 token 的 4×4 矩阵，定义：

RowNormϵ(A)ij=Aij∑kAik+ϵ,ColNormϵ(A)ij=Aij∑kAkj+ϵ \operatorname{RowNorm}_{\epsilon}(A)_{ij}=\frac{A_{ij}}{\sum_k A_{ik}+\epsilon},\qquad \operatorname{ColNorm}_{\epsilon}(A)_{ij}=\frac{A_{ij}}{\sum_k A_{kj}+\epsilon}

先完成初始化：

A(0)=Softmaxrow(C0)+ϵhc,C(0)=ColNormϵhc(A(0)) A^{(0)}=\operatorname{Softmax}_{\mathrm{row}}(C_0)+\epsilon_{\mathrm{hc}},\qquad C^{(0)}=\operatorname{ColNorm}_{\epsilon_{\mathrm{hc}}}(A^{(0)})

再重复 19 次：

C(t)=ColNormϵhc(RowNormϵhc(C(t−1))),t=1,…,19 C^{(t)}=\operatorname{ColNorm}_{\epsilon_{\mathrm{hc}}}\!\left(\operatorname{RowNorm}_{\epsilon_{\mathrm{hc}}}(C^{(t-1)})\right),\quad t=1,\ldots,19

comb=C(19):[B*S,4,4] comb=C^{(19)}:[B*S,4,4]

也就是 1 次行 Softmax＋20 次列归一化＋19 次普通行归一化。有限迭代和分母中的 epsilon 使行列和只是近似 1。这种约束限制残差混合的总系数，不等于保证所有残差向量不同，也不保证每个向量范数严格不变。核查：hc_split_sinkhorn

图 3 待修订：底部公式的括号容易把 epsilon 画成 Softmax 的输入；正确位置是 行 Softmax 之后加 epsilon，再列归一化。原图保留，以上公式为准。图中的 Sinkhorn^19 表示 19 次“行归一化→列归一化”，不是再执行 19 套各 20 轮的完整算法。

3.3 hc_pre：四路各乘一个系数，再求和

图 4 · 每一行代表一个 token。一个系数作用于这一行的全部 5120 个元素，最后只对四条残差流求和，不对 token 或 hidden 维求和。

输入为 X:[B*S,4,5120]X:[B*S,4,5120] 和当前使用的 precur:[B*S,4]pre_{\mathrm{cur}}:[B*S,4]：

Zt,d=∑i=03precur,t,iXt,i,d Z_{t,d}=\sum_{i=0}^{3}pre_{\mathrm{cur},t,i}X_{t,i,d}

输出 Z:[B*S,5120]Z:[B*S,5120]。图中的单列 aia_i 是 precur[:,i]pre_{\mathrm{cur}}[:,i]，为表示广播可写成 [B*S,1]；不是全体 token 共享同一个标量。这个乘加本身没有新权重，生成系数的参数已在上节计入。

3.4 hc_post：旧残差混合＋子层输出写回

图 5 · 两条路径先分别形成四路结果，再逐元素相加。右半图是在解释其中一个输出流，不是另一套算法。

输入 X:[B*S,4,5120]X:[B*S,4,5120]、Y:[B*S,5120]Y:[B*S,5120]、post:[B*S,4]post:[B*S,4]、comb:[B*S,4,4]comb:[B*S,4,4]。约定 comb[t,i,j] 表示旧第 ii 路到新第 jj 路的系数：

X′t,j,d=postt,jYt,d+∑i=03combt,i,jXt,i,d X'_{t,j,d}=post_{t,j}Y_{t,d}+\sum_{i=0}^{3}comb_{t,i,j}X_{t,i,d}

输出 X′:[B*S,4,5120]X':[B*S,4,5120]。第一项把同一个子层输出按不同强度写到四路；第二项把旧四路重新组合。两项都不改变 hidden 维度。

图 5 待修订：右半边应固定输出流 j，并遍历四个输入流 i。输入必须包含全部 X₀～X₃；comb[:,:,j] 为 [B*S,4]，post[:,j] 广播时为 [B*S,1]，而不是图中标出的宽度 4。四个加权残差项与一个加权 Y 相加，才得到单路 X′j:[B*S,5120]X'_j:[B*S,5120]。

3.5 Single-Pass：提前的是下一个子层的 pre

这三步的功能关系与系数使用时序要分开。当前四路 XX 可同时作为两条路径的输入：一条拿已经准备好的 pre_cur 做汇聚；另一条产生 pre_next、当前 post 和当前 comb。它们只是数据依赖上允许重叠，不等于 Python 参考代码必然并发执行。

Layer 0 MoE 侧 本层 MoE 出口 Layer 1 Attention 入口

Layer 0 最开始用固定 pre_cur=[1,0,0,0]。每次联合生成的是 24 个运行时系数，不是 24 个模型参数。核查：Block.forward

4. 两个入口 RMSNorm

RMSNorm 对单路输入的每个 token 独立计算：

Ut,d=γdZt,d(15120∑k=05119Zt,k2+10−20)−1/2 U_{t,d}=\gamma_d Z_{t,d}\left(\frac{1}{5120}\sum_{k=0}^{5119}Z_{t,k}^2+10^{-20}\right)^{-1/2}

输入输出都是 [B*S,5120]。γ:[5120]\gamma:[5120] 可学习，没有加法偏置；不减均值。Attention 与 MoE 的入口各有一套，合计 10,240 个权重。这里与 mHC 的 RMS 因子不同：mHC 统计的是四路展平后的 20480 维，且没有独立 gamma。核查：RMSNorm

5.2 完整打分、mask、归一化、加权汇总

以完整序列 Shis=SS_{\mathrm{his}}=S 为例，数学上保留每个 Query 对本会话全部 S 个位置的分数；batch 之间不互相打分。固定会话 b 和头 h：

Eb,h=Qb,hCbT/512,Lb,h=Eb,h+Mb E_{b,h}=Q_{b,h}C_b^T/\sqrt{512},\qquad L_{b,h}=E_{b,h}+M_b

Mb,i,j={0,0≤pb,i−pb,j<128−∞,其他 M_{b,i,j}=\begin{cases}0,&0\le p_{b,i}-p_{b,j}<128\\-\infty,&\text{其他}\end{cases}

窗口是主对角线及以下 127 条对角线，不是完整下三角。带每头 sink 标量 aha_h 的权重与汇总为：

Pb,h,i,j=exp(Lb,h,i,j)exp(ah)+∑k=0S−1exp(Lb,h,i,k),Ob,h=Pb,hCb P_{b,h,i,j}=\frac{\exp(L_{b,h,i,j})}{\exp(a_h)+\sum_{k=0}^{S-1}\exp(L_{b,h,i,k})},\qquad O_{b,h}=P_{b,h}C_b

5.3 输出恢复与两级分组投影

对 O 每头最后 64 维按当前 Query 位置做逆 RoPE，随后：
