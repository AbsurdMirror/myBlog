Layer 1：从 Engram 写入到局部注意力与 MoE

1. 相对 Layer 0，只看两处差异

本文分析 DeepSeek-V4.1-Flash 的 Layer 1。Layer 0 已经完整讲过 mHC、RMSNorm、局部 Attention / SWA 和 MoE；Layer 1 不再重复这些推导，而是回答两个新问题：

  1. Engram 怎样在普通 Transformer Block 之前，根据当前 token 及其局部历史检索条件记忆，并写回四路残差？
  2. Layer 1 的第一次 hc_pre 为什么不再使用固定的 [1,0,0,0][1,0,0,0]，而是使用 Layer 0 MoE 侧传来的动态 pre_next？

记

N=BS,D=5120,C=4,W=128. N=BS,\qquad D=5120,\qquad C=4,\qquad W=128.

Layer 1 从 Layer 0 接收：

Xin(1):[B,S,4,5120](BF16),pnext(0):[B,S,4](FP32). X^{(1)}_{\mathrm{in}}:[B,S,4,5120]\quad\text{(BF16)}, \qquad p^{(0)}_{\mathrm{next}}:[B,S,4]\quad\text{(FP32)}.

其中 Xin(1)X^{(1)}_{\mathrm{in}} 是四路残差，pnext(0)p^{(0)}_{\mathrm{next}} 是 Layer 0 的 MoE 侧 mHC 生成的下一次汇聚系数。完整数据流为：

(Xin(1),pnext(0))→Engram→Layer1Block→(Xout(1),pnext(1)) \boxed{ (X^{(1)}_{\mathrm{in}},p^{(0)}_{\mathrm{next}}) \rightarrow \mathrm{Engram} \rightarrow \mathrm{Layer\ 1\ Block} \rightarrow (X^{(1)}_{\mathrm{out}},p^{(1)}_{\mathrm{next}}) }

逐步对照如下。“结构相同”只表示算子、shape 和执行顺序与 Layer 0 相同；Layer 1 拥有自己的参数，输入数值也已经被 Engram 改变，并不与 Layer 0 共享权重或计算结果。

步骤 相对 Layer 0 Layer 1 的行为
1. Engram Hash、查表、门控与四路写回 新增 在普通 Block 前修改四路残差；不修改传入的 pre_next
2. Attention 侧 mHC 系数生成 结构相同 从 Engram 更新后的四路残差预测本层 attn_pre/post/comb
3. Attention 入口 hc_pre 输入不同 使用 Layer 0 MoE 侧生成的动态 pre_next，不再使用 identity-pre
4. Attention 入口 RMSNorm 结构相同 独立参数，输入来自步骤 3
5. Local Attention / SWA 结构相同 仍是 128-token 局部窗口，没有 compressed/global KV 或 Indexer
6. Attention 侧 hc_post 结构相同 融合 Attention 输出和 Engram 更新后的四路残差
7. MoE 侧 mHC 系数生成 结构相同 生成本层 ffn_pre/post/comb
8. MoE 入口 hc_pre 结构相同 使用本层 Attention 侧生成的 attn_pre
9. MoE 入口 RMSNorm 结构相同 独立参数
10. MoE FFN 结构相同 384 个 routed experts 选 6 个，并执行 1 个 shared expert
11. MoE 侧 hc_post 结构相同 输出四路残差，并把 ffn_pre 作为下一层的 pre_next

固定配置中 compress_ratios[1]=0，而 kv_source_layers 与 index_source_layers 都从 Layer 2 开始。因此 Layer 1 与 Layer 0 一样只执行 SWA；本页新增的注意力外路径只有 Engram。配置核查

计算分为五步。

Token 压缩

原始 Token ID 的取值范围来自大小为 129,280 的词表。Hash 之前先通过固定映射 TmapT_{\mathrm{map}} 得到压缩 ID：

Tc,b,t=Tmap[Tb,t],Tc:[B,S]. T_{c,b,t}=T_{\mathrm{map}}\!\left[T_{b,t}\right], \qquad T_c:[B,S].

固定配置把原始 Token 映射到 99,092 个压缩 ID。映射构建时会对能够完整解码的 token 文本执行 Unicode 规范化、去音调、转小写、空白折叠和首尾空白处理；规范化结果相同的 token 共用压缩 ID。TmapT_{\mathrm{map}} 是固定运行时 buffer，不是可学习参数。

组织当前 token 与历史 token

图中的 G0G_0 表示当前位置的压缩 Token ID，G1,G2,G3G_1,G_2,G_3 依次向历史回看一步、两步和三步。Prefill 与 Decode 可能分属不同次前向，因此实现还维护压缩 Token 历史 cache，使当前前向能够读取此前已经写入的历史。

记 Gb,t,rG_{b,t,r} 为位置 tt 向前回看 rr 步得到的输入，r=0,1,2,3r=0,1,2,3：

Gb,t,r={Tc,b,t−r,t−r≥0∧[t−r,t] 内全部有效,tpad,其他. G_{b,t,r}= \begin{cases} T_{c,b,t-r},& t-r\ge 0\ \land\ [t-r,t]\text{ 内全部有效},\\ t_{\mathrm{pad}},& \text{其他}. \end{cases}

序列开头缺少的历史使用固定 tpadt_{\mathrm{pad}}。多模态输入中的图像 span 会在压缩缓存中写入无效标记；任何跨过无效位置的 NN-gram 都会被阻断并改用 tpadt_{\mathrm{pad}}，避免把文本与图像位置拼成错误的局部短语。

构造 2、3、4-gram Hash

Layer 1 为四个回看位置准备四个固定奇数乘数 μ0,μ1,μ2,μ3\mu_0,\mu_1,\mu_2,\mu_3。先逐位置相乘，再通过 XOR 累积，分别得到 2、3、4-gram Hash：

Hb,t,n=⨁r=0n−1(Gb,t,rμr),n∈{2,3,4}. H_{b,t,n} = \bigoplus_{r=0}^{n-1} \left(G_{b,t,r}\mu_r\right), \qquad n\in\{2,3,4\}.

对应关系是：

Hb,t,2=(Gb,t,0μ0)⊕(Gb,t,1μ1),Hb,t,3=Hb,t,2⊕(Gb,t,2μ2),Hb,t,4=Hb,t,3⊕(Gb,t,3μ3). \begin{aligned} H_{b,t,2} &=(G_{b,t,0}\mu_0)\oplus(G_{b,t,1}\mu_1),\\ H_{b,t,3} &=H_{b,t,2}\oplus(G_{b,t,2}\mu_2),\\ H_{b,t,4} &=H_{b,t,3}\oplus(G_{b,t,3}\mu_3). \end{aligned}

因此，同一个当前 token 会同时保留二元、三元和四元局部上下文，而不是只使用最长的 4-gram。

生成 24 个查表地址

每种 NN-gram 都进入八个 Hash head。对阶数 n∈{2,3,4}n\in\{2,3,4\} 和 head q∈{0,…,7}q\in\{0,\ldots,7\}，地址为：

IE,b,t,n,q=Hoff,n,q+(Hb,t,nmodHmod,n,q). I_{E,b,t,n,q} = H_{\mathrm{off},n,q} + \left( H_{b,t,n}\bmod H_{\mathrm{mod},n,q} \right).

Hmod,n,qH_{\mathrm{mod},n,q} 是该分区使用的质数模数，Hoff,n,qH_{\mathrm{off},n,q} 是它在大表中的起始位置。不同 (n,q)(n,q) 使用互不重叠的地址区间，因此逻辑上可以理解为 24 张小表，参数存储上则拼接为一张连续大表。

把三种阶数与八个 head 展平：

IE:[B,S,3,8]→[B,S,24]. I_E:[B,S,3,8]\rightarrow[B,S,24].

查表并展平

Layer 1 的 Engram 参数表为：

Etable:[384006168,256]. E_{\mathrm{table}}:[384006168,256].

每个地址读取一行 256 维向量：

Eb,t,n,q,:=Etable[IE,b,t,n,q,:], E_{b,t,n,q,:} = E_{\mathrm{table}} \left[ I_{E,b,t,n,q},: \right],

因此查表结果为：

E:[B,S,3,8,256]→[B,S,24,256]. E:[B,S,3,8,256] \rightarrow [B,S,24,256].

最后把 24 行沿特征维展平：

Eflat:[B,S,6144],6144=3×8×256. \boxed{ E_{\mathrm{flat}}:[B,S,6144] }, \qquad 6144=3\times8\times256.

至此，图 1 的输出已经包含当前 token 对应的 24 份局部短语记忆。这里的“24 次查表”是逻辑行读取口径；固定 revision 的官方推理实现会分别读取 FP8 数据与对应 scale，不能直接把逻辑行数等同于底层访存指令数。

在官方推理实现中，模型会在进入各层循环之前，同时生成 Layer 1 和 Layer 14 所需的 Hash 地址：

Iall:[B,S,2,24]. I_{\mathrm{all}}:[B,S,2,24].

执行 Layer 1 时只取第一个切片 Iall[:,:,0,:]I_{\mathrm{all}}[:,:,0,:]。图 1 为了说明 Layer 1 的算子数据流，只画出了这个 [B,S,24][B,S,24] 切片。

2.2 从查表结果到四路残差写回

图 2 接续图 1 的输出 EflatE_{\mathrm{flat}}。查表结果先投影为四路 Key 和一份共享 Value，再与四路残差分别计算 Gate，最后把同一份 Value 按不同幅度写回四路。

主要输入和参数如下：

对象 Shape 含义

XX [B,S,4,5120][B,S,4,5120] Layer 0 输出的四路残差
WEW_E [25600,6144][25600,6144] 生成 Key 和 Value 的投影权重，无 bias

官方推理实现将 Engram 表的 FP8 数据按 scale 还原为 BF16。进入 Gate 分支后，X,KE,VE,WQ,WKX,K_E,V_E,W_Q,W_K 显式转换为 FP32 参与计算；最终输出 YY 再转换回 XX 的 dtype，本配置中为 BF16。

生成四路 Key 和共享 Value

查表结果与 WEW_E 相乘：

F=EflatWE𝖳,F:[B,S,25600]. F=E_{\mathrm{flat}}W_E^{\mathsf T}, \qquad F:[B,S,25600].

沿最后一维按 20480+512020480+5120 切分：

[KE,VE]=split(F,[20480,5120]), [K_E,V_E] =\operatorname{split}(F,[20480,5120]),

KE:[B,S,4,5120],VE:[B,S,5120]. K_E:[B,S,4,5120], \qquad V_E:[B,S,5120].

KEK_E 包含四路不同的 Key，VEV_E 只有一份共享 Value。Engram 不会为四路分别生成四份 Value；四路写入差异来自后面各自计算的 Gate。

计算四路 RMS 缩放因子

两组可学习参数先逐元素相乘：

W=WQ⊙WK,W:[4,5120]. W=W_Q\odot W_K, \qquad W:[4,5120].

对四路残差 XX 和四路 Key KEK_E 分别沿 5120 维计算 RMS 倒数。对残差流 c∈{0,1,2,3}c\in\{0,1,2,3\}：

rb,t,cX=(15120∑d=05119Xb,t,c,d2+ϵ)−1/2, r^X_{b,t,c} = \left( \frac{1}{5120} \sum_{d=0}^{5119}X_{b,t,c,d}^{2} +\epsilon \right)^{-1/2},

rb,t,cK=(15120∑d=05119KE,b,t,c,d2+ϵ)−1/2,ϵ=10−20. r^K_{b,t,c} = \left( \frac{1}{5120} \sum_{d=0}^{5119}K_{E,b,t,c,d}^{2} +\epsilon \right)^{-1/2}, \qquad \epsilon=10^{-20}.

rXr^X 与 rKr^K 的 Shape 都是 [B,S,4][B,S,4]。它们只是当前输入动态生成的缩放因子，没有额外的可学习 RMSNorm 权重。

由加权点积生成 Gate

每一路分别计算归一化加权点积：

Db,t,c=rb,t,cXrb,t,cK5120∑d=05119Xb,t,c,dWc,dKE,b,t,c,d, D_{b,t,c} = \frac{r^X_{b,t,c}r^K_{b,t,c}}{\sqrt{5120}} \sum_{d=0}^{5119} X_{b,t,c,d} W_{c,d} K_{E,b,t,c,d},

D:[B,S,4]. D:[B,S,4].

官方推理实现不会直接把 DD 输入 Sigmoid，而是先执行 Signed Sqrt：

D̃b,t,c=copysign(max(|Db,t,c|,10−6),Db,t,c). \widetilde D_{b,t,c} = \operatorname{copysign} \left( \sqrt{\max\left(|D_{b,t,c}|,10^{-6}\right)}, D_{b,t,c} \right).

这里使用 copysign\operatorname{copysign}，因此 D=0D=0 时也按照源码复制正号，而不是把结果写成零。随后得到四路 Gate：

gb,t,c=σ(D̃b,t,c),g:[B,S,4]. g_{b,t,c}=\sigma\!\left(\widetilde D_{b,t,c}\right), \qquad g:[B,S,4].

纯文本输入不需要额外处理。多模态输入中，图像位置的 Gate 在 Sigmoid 之后被 mask 置零：

gb,t,c←{gb,t,c,Tmask,b,t=1,0,Tmask,b,t=0. g_{b,t,c}\leftarrow \begin{cases} g_{b,t,c},&T_{\mathrm{mask},b,t}=1,\\ 0,&T_{\mathrm{mask},b,t}=0. \end{cases}

图 2 为了压缩画面，把 TmaskT_{\mathrm{mask}} 的箭头画在 Sigmoid 附近；源码执行顺序是先计算 Sigmoid，再应用 mask。

把共享 Value 写回四路残差

同一个 VEV_E 广播到四路，每一路使用自己的 Gate：

Yb,t,c,d=Xb,t,c,d+gb,t,cVE,b,t,d, \boxed{ Y_{b,t,c,d} = X_{b,t,c,d} +g_{b,t,c}V_{E,b,t,d} },

Y:[B,S,4,5120]. Y:[B,S,4,5120].

因此，Engram 写回具有三个特征：

  1. 四路共享同一份 VEV_E。
  2. 四路分别使用自己的 gb,t,cg_{b,t,c}，写入幅度可以不同。
  3. Engram 只更新四路残差；Layer 0 传来的动态 pre_next 原样保留，继续交给 Layer 1 的第一次 hc_pre。

Required Global Memory 理论下界（理想融合口径）

与 Layer 0 相同，这里把 Engram 视为一个逻辑分析单元，并采用以下假设：

  • Weight：参数和量化 scale 长期保存在 Global Memory。
  • I/O：完整输入与输出保存在 Global Memory，并分别计数。
  • Internal Activation：Eflat,F,KE,VE,D,gE_{\mathrm{flat}},F,K_E,V_E,D,g 等中间量允许通过融合、分块或工作区复用，不要求全部完整写回 Global Memory。

3. Layer 1 第一次 hc_pre 的真正变化

模型只在最初把 embedding 扩成四路时创建一次 identity-pre：

pidentity=[1,0,0,0]. p^{\mathrm{identity}}=[1,0,0,0].

Layer 0 的 Attention 入口使用它；Layer 0 执行结束后返回 MoE 侧生成的 ffn_pre，即 pnext(0)p^{(0)}_{\mathrm{next}}。Layer 1 不会重新创建 identity-pre，而是直接用这个动态状态汇聚 Engram 更新后的四路残差：

Zb,t,d(1)=∑c=03pnext,b,t,c(0)X′b,t,c,d,Z(1):[B,S,5120]. \boxed{ Z^{(1)}_{b,t,d} =\sum_{c=0}^{3} p^{(0)}_{\mathrm{next},b,t,c} X'_{b,t,c,d} }, \qquad Z^{(1)}:[B,S,5120].

与此同时，Layer 1 Attention 侧的 hc_mixes 已经从 X′X' 预测出新的 attn_pre/post/comb。但这里的第一次 hc_pre 仍使用上一层传来的 pnext(0)p^{(0)}_{\mathrm{next}}；本层新生成的 attn_pre 留给紧随其后的 MoE 入口。顺序是：

pnext(0)⏟Layer 0 MoE 产生→Layer1Attentionhc_prepA(1)⏟Layer 1 Attention 产生→Layer1MoEhc_prepnext(1)⏟Layer 1 MoE 产生. \underbrace{p^{(0)}_{\mathrm{next}}}_{\text{Layer 0 MoE 产生}} \xrightarrow{\mathrm{Layer\ 1\ Attention\ hc\_pre}} \underbrace{p^{(1)}_{A}}_{\text{Layer 1 Attention 产生}} \xrightarrow{\mathrm{Layer\ 1\ MoE\ hc\_pre}} \underbrace{p^{(1)}_{\mathrm{next}}}_{\text{Layer 1 MoE 产生}}.

这正是 Single-Pass mHC 的跨子层、跨层系数传递。与 Layer 0 相比，Layer 1 的 hc_pre 算法没有变化，变化的是第一次调用的系数来源。Block.forward

4. 继承自 Layer 0 的模块

Engram 写回之后，Layer 1 进入与 Layer 0 同构的 Block。下面只记录复用关系；公式、shape 和内部步骤见 Layer 0：从四路残差到局部注意力与 MoE。

模块 Layer 1 相对 Layer 0 需要记住的差别
Attention 侧 mHC 算法与 shape 相同，参数独立 系数从 Engram 更新后的 X′X' 预测；首次汇聚用动态 pre_next
两个入口 RMSNorm 相同结构，参数独立 输入数值不同
Local Attention / SWA 相同结构，参数独立 同为 128-token 窗口；没有 global KV、Compressor 或 Indexer

Layer1=Layer0基准Block+前置Engram+动态跨层pre \boxed{ \mathrm{Layer\ 1} =\mathrm{Layer\ 0\ 基准\ Block} +\mathrm{前置\ Engram} +\mathrm{动态跨层\ pre} }

这里的加号表示结构差异，不表示参数共享。

核心结论只有三条：

  1. Layer 1 是 Layer 0 基准 Block 的第一次结构扩展。 新增 Engram，但 Attention 仍是纯 128-token SWA，MoE 与 mHC 主体不变。
  2. Engram 向四路写入共享 Value、独立 Gate。 它更新四路残差，却不改动 Layer 0 传来的动态 pre_next。
  3. 本层容量主要由条件记忆决定。 单个 Engram 带来 98.463B 逻辑参数和约 94.562 GiB 的 world_size=1 权重驻留；实际部署依赖行分片、预取或 host-memory offload，而不是把它理解成必须单卡常驻的普通线性层。
