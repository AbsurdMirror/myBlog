Layer 1：从 Engram 写入到局部注意力与 MoE

1. Layer 1 总览

Layer 1 从 Layer 0 接收：

Xin:[B,S,4,5120](BF16),pnext:[B,S,4](FP32). X_{\mathrm{in}}:[B,S,4,5120]\quad\text{(BF16)}, \qquad p_{\mathrm{next}}:[B,S,4]\quad\text{(FP32)}.

其中 XinX_{\mathrm{in}} 是四路残差，pnextp_{\mathrm{next}} 是 Layer 0 的 MoE 侧 mHC 生成的下一次汇聚系数。

Layer 1 向 Layer 2 输出：

Xout:[B,S,4,5120](BF16),ffn_pre:[B,S,4](FP32). X_{\mathrm{out}}:[B,S,4,5120]\quad\text{(BF16)}, \qquad \mathrm{ffn\_pre}:[B,S,4]\quad\text{(FP32)}.

其中 XoutX_{\mathrm{out}} 是本层更新后的四路残差，ffn_pre 是本层 MoE 侧 mHC 生成的汇聚系数，作为 Layer 2 的 pre_next。

完整数据流为：

(Xin,pnext)→Engram→Layer1Block→(Xout,ffn_pre) \boxed{ (X_{\mathrm{in}},p_{\mathrm{next}}) \rightarrow \mathrm{Engram} \rightarrow \mathrm{Layer\ 1\ Block} \rightarrow (X_{\mathrm{out}},\mathrm{ffn\_pre}) }

Layer 1 先通过 Engram 更新四路残差，再依次执行 Attention 和 MoE，两侧均通过 mHC 完成四路残差的汇聚与融合。与 Layer 0 相比，本层新增前置 Engram，Attention 入口则使用上一层传入的动态 pre_next；Engram 不修改这份系数，后续章节将展开说明。各步骤的作用及其与前文的关系如下；结构相同的算子仍使用本层独立参数。

步骤 Layer 1 的行为 与前文的关系
1. Engram 根据 Token 及其局部历史查表，结合四路残差计算门控并写回；传入的 pre_next 保持不变 本文重点展开
2. mHC 混合系数生成 根据 Engram 更新后的四路残差，生成 Attention 侧混合系数 与 Layer 0 相同
3. mHC 汇聚 使用 Layer 0 传入的动态 pre_next，将四路残差汇聚为单路特征 系数来源不同，本文重点说明
4. RMSNorm 对单路特征归一化，得到 Attention 输入 与 Layer 0 相同
5. Local Attention / SWA 接收归一化后的输入，在 128-token 局部窗口内计算注意力，输出单路特征 与 Layer 0 相同
6. mHC 残差融合 使用 Attention 侧混合系数，将 Attention 输出与四路残差融合，得到更新后的四路残差 与 Layer 0 相同
7. mHC 混合系数生成 根据更新后的四路残差，生成 MoE 侧混合系数 与 Layer 0 相同
8. mHC 汇聚 使用 attn_pre，将更新后的四路残差汇聚为单路特征 与 Layer 0 相同
9. RMSNorm 对单路特征归一化，得到 MoE 输入 与 Layer 0 相同
10. MoE FFN 接收归一化后的输入，经专家路由与前馈计算，输出单路特征 与 Layer 0 相同
11. mHC 残差融合 使用 MoE 侧混合系数，将 MoE 输出与四路残差融合，得到本层输出四路残差 与 Layer 0 相同

2. Engram

Engram 位于普通 Transformer Block 之前，根据当前 Token 及其局部历史检索记忆，再将检索结果写入四路残差。Token 决定读取哪些记忆，四路残差则参与判断每一路的写入幅度。

整个过程分为两部分：先对 Token 进行压缩、组织局部历史，再通过 Hash 生成地址并查表，得到检索结果 EflatE_{\mathrm{flat}}；随后将检索结果投影为四路 Key 和一份共享 Value，结合四路残差计算各自的 Gate，将共享 Value 按不同幅度加回四路。输入 XX 与输出 YY 的 Shape 均为 [B,S,4,5120][B,S,4,5120]，上一层传入的 pre_next 保持不变。

图中合并展示 B、S 两个维度。

下文按以下三部分展开：

  • 2.1 从 Token 到 24 个查表结果：说明 Token 压缩、局部历史组织、Hash 地址生成与查表，得到 EflatE_{\mathrm{flat}}。
  • 2.2 从查表结果到四路残差写回：说明 Key / Value 投影、四路 Gate 的计算，以及共享 Value 的残差写回。
  • 2.3 参数量、计算量与 Required Global Memory 理论下界：分析本层 Engram 的参数量、前向计算量与内存需求。

2.1 从 Token 到 24 个查表结果

输入 Token ID 为 T:[B,S]T:[B,S]。图中从左到右完成 Token 压缩、局部历史组织、Hash 地址生成与查表，最终得到每个位置的 6144 维检索结果，交给 2.2 计算门控并写回残差。

2.1.1 Token 压缩与历史组织

原始词表大小为 129,280。Hash 之前先通过固定映射 Tmap:[129280]T_{\mathrm{map}}:[129280] 得到压缩 ID：

Tc,b,t=Tmap[Tb,t],Tc:[B,S]. T_{c,b,t}=T_{\mathrm{map}}\!\left[T_{b,t}\right], \qquad T_c:[B,S].

固定配置将原始 Token 映射到 99,092 个压缩 ID。构建映射时，对能够完整解码的 token 文本进行 Unicode 规范化、去音调、转小写和空白整理，规范化结果相同的 token 共用压缩 ID。该映射是固定运行时 buffer，不是可学习参数。

压缩后组织四个位置的输入：G0G_0 为当前 token，G1,G2,G3G_1,G_2,G_3 分别向历史回看一步、两步和三步，各自的 Shape 均为 [B,S][B,S]。Prefill 与 Decode 可能分属不同次前向，因此实现还维护压缩 Token 历史 cache，供当前前向读取此前写入的历史。

记 Gb,t,rG_{b,t,r} 为位置 tt 向前回看 rr 步得到的输入，r=0,1,2,3r=0,1,2,3：

Gb,t,r={Tc,b,t−r,t−r≥0∧[t−r,t] 内全部有效,tpad,其他. G_{b,t,r}= \begin{cases} T_{c,b,t-r},& t-r\ge 0\ \land\ [t-r,t]\text{ 内全部有效},\\ t_{\mathrm{pad}},& \text{其他}. \end{cases}

序列开头缺少的历史使用固定 tpadt_{\mathrm{pad}}。图中的 T_mask 是区分文本与图像位置的 BOOL mask；图像位置在压缩缓存中被标为无效，跨过无效位置的 n-gram 输入也会改用 tpadt_{\mathrm{pad}}，避免将文本与图像位置拼成局部短语。

2.1.2 Hash 与查表地址生成

Layer 1 为四个位置准备固定奇数乘数 μ0,μ1,μ2,μ3\mu_0,\mu_1,\mu_2,\mu_3。先逐位置相乘，再通过 XOR（记作 ⊕\oplus）累积，得到图中三路 2、3、4-gram Hash：

Hb,t,2=(Gb,t,0μ0)⊕(Gb,t,1μ1),Hb,t,3=Hb,t,2⊕(Gb,t,2μ2),Hb,t,4=Hb,t,3⊕(Gb,t,3μ3). \begin{aligned} H_{b,t,2} &=(G_{b,t,0}\mu_0)\oplus(G_{b,t,1}\mu_1),\\ H_{b,t,3} &=H_{b,t,2}\oplus(G_{b,t,2}\mu_2),\\ H_{b,t,4} &=H_{b,t,3}\oplus(G_{b,t,3}\mu_3). \end{aligned}

H2,H3,H4H_2,H_3,H_4 的 Shape 均为 [B,S][B,S]，分别表示当前 token 对应的二元、三元和四元局部上下文。

每种 n-gram 再进入八个 Hash head。固定 buffer HmodH_{\mathrm{mod}} 和 HoffH_{\mathrm{off}} 的 Shape 均为 [3,8][3,8]：前者给出每个分区的质数模数，后者给出该分区在大表中的起始位置。对阶数 n∈{2,3,4}n\in\{2,3,4\} 和 head q∈{0,…,7}q\in\{0,\ldots,7\}，先取模，再加 offset，生成查表地址：

IE,b,t,n,q=Hoff,n,q+(Hb,t,nmodHmod,n,q). I_{E,b,t,n,q} = H_{\mathrm{off},n,q} + \left( H_{b,t,n}\bmod H_{\mathrm{mod},n,q} \right).

这里用阶数 nn 标记 buffer 对应的行；n=2,3,4n=2,3,4 依次对应图中的第 0、1、2 行。不同 (n,q)(n,q) 使用互不重叠的地址区间，逻辑上相当于 24 张小表，参数存储上拼接为一张连续大表。三种阶数乘八个 head，每个 token 共得到 24 个地址：

IE:[B,S,3,8]→[B,S,24]. I_E:[B,S,3,8]\rightarrow[B,S,24].

官方推理实现会在进入各层循环之前，同时生成 Layer 1 和 Layer 14 的地址，得到 Iall:[B,S,2,24]I_{\mathrm{all}}:[B,S,2,24]。执行 Layer 1 时取切片 Iall[:,:,0,:]I_{\mathrm{all}}[:,:,0,:]；图中只展示该层的 [B,S,24][B,S,24] 地址。

2.1.3 查表与展平

Layer 1 的 Engram 参数表为 Etable:[384006168,256]E_{\mathrm{table}}:[384006168,256]。每个地址读取一行 256 维向量：

Eb,t,n,q,:=Etable[IE,b,t,n,q,:], E_{b,t,n,q,:} = E_{\mathrm{table}} \left[ I_{E,b,t,n,q},: \right],

查表后先将三种阶数与八个 head 合并为 24 行，再将每行的 256 维沿特征维展平：

E:[B,S,3,8,256]→[B,S,24,256]→Eflat:[B,S,6144]. E:[B,S,3,8,256] \rightarrow [B,S,24,256] \rightarrow E_{\mathrm{flat}}:[B,S,6144].

其中 6144=3×8×2566144=3\times8\times256。输出 EflatE_{\mathrm{flat}} 汇集了当前 token 对应的 24 份局部短语记忆，接下来进入 2.2 的 Key / Value 投影与四路门控。

2.2 从查表结果到四路残差写回

图 3 接续图 2 的输出 EflatE_{\mathrm{flat}}。查表结果先投影为四路 Key 和一份共享 Value，再与四路残差分别计算 Gate，最后把同一份 Value 按不同幅度写回四路。

2.2.1 生成四路 Key 与共享 Value

查表结果 Eflat:[B,S,6144]E_{\mathrm{flat}}:[B,S,6144] 与无 bias 的投影权重 WE:[25600,6144]W_E:[25600,6144] 相乘：

F=EflatWE𝖳,F:[B,S,25600]. F=E_{\mathrm{flat}}W_E^{\mathsf T}, \qquad F:[B,S,25600].

沿最后一维按 20480+512020480+5120 切分，再将 Key 的 20480 维重排为四路、每路 5120 维：

[FK,VE]=split(F,[20480,5120]), [F_K,V_E] =\operatorname{split}(F,[20480,5120]),

KE=reshape(FK,[B,S,4,5120]),VE:[B,S,5120]. K_E=\operatorname{reshape}(F_K,[B,S,4,5120]), \qquad V_E:[B,S,5120].

KE:[B,S,4,5120]K_E:[B,S,4,5120] 包含四路不同的 Key，VEV_E 只有一份，供四路共享。图中 FF 的虚线表示这两部分的切分位置，四路写入幅度由后面的 Gate 决定。

2.2.2 计算四路 Gate

四路残差 X:[B,S,4,5120]X:[B,S,4,5120] 与 KEK_E 分别沿 5120 维计算 RMS 倒数。对残差流 c∈{0,1,2,3}c\in\{0,1,2,3\}：

rb,t,cX=(15120∑d=05119Xb,t,c,d2+ϵ)−1/2, r^X_{b,t,c} = \left( \frac{1}{5120} \sum_{d=0}^{5119}X_{b,t,c,d}^{2} +\epsilon \right)^{-1/2},

rb,t,cK=(15120∑d=05119KE,b,t,c,d2+ϵ)−1/2,ϵ=10−20. r^K_{b,t,c} = \left( \frac{1}{5120} \sum_{d=0}^{5119}K_{E,b,t,c,d}^{2} +\epsilon \right)^{-1/2}, \qquad \epsilon=10^{-20}.

rXr^X 与 rKr^K 的 Shape 都是 [B,S,4][B,S,4]。它们只是当前输入动态生成的缩放因子，没有额外的可学习 RMSNorm 权重。

另一条分支将两组可学习的逐维缩放参数 WQ,WK:[4,5120]W_Q,W_K:[4,5120] 逐元素相乘：

W=WQ⊙WK,W:[4,5120]. W=W_Q\odot W_K, \qquad W:[4,5120].

两路 RMS 因子与逐维权重汇入图中的加权点积。每一路分别沿特征维求和，再乘归一化因子，得到评分：

Db,t,c=rb,t,cXrb,t,cK5120∑d=05119Xb,t,c,dWc,dKE,b,t,c,d,D:[B,S,4]. D_{b,t,c} = \frac{r^X_{b,t,c}r^K_{b,t,c}}{\sqrt{5120}} \sum_{d=0}^{5119} X_{b,t,c,d} W_{c,d} K_{E,b,t,c,d}, \qquad D:[B,S,4].

评分先经过 Signed Sqrt：保留符号，对绝对值设置下限后开平方。

D̃b,t,c=copysign(max(|Db,t,c|,10−6),Db,t,c). \widetilde D_{b,t,c} = \operatorname{copysign} \left( \sqrt{\max\left(|D_{b,t,c}|,10^{-6}\right)}, D_{b,t,c} \right).

这里使用 copysign\operatorname{copysign}，因此 D=0D=0 时也按照源码复制正号，而不是把结果写成零。随后得到四路 Gate：

gb,t,c=σ(D̃b,t,c),g:[B,S,4]. g_{b,t,c}=\sigma\!\left(\widetilde D_{b,t,c}\right), \qquad g:[B,S,4].

多模态输入使用文本位置 mask Tmask:[B,S]T_{\mathrm{mask}}:[B,S]，广播到四路，在 Sigmoid 之后将图像位置的 Gate 置零：

gb,t,c←{gb,t,c,Tmask,b,t=1,0,Tmask,b,t=0. g_{b,t,c}\leftarrow \begin{cases} g_{b,t,c},&T_{\mathrm{mask},b,t}=1,\\ 0,&T_{\mathrm{mask},b,t}=0. \end{cases}

纯文本输入无需这一步。图中的 mask(sigmoid) 合并表示 Sigmoid 与随后应用的文本位置 mask。

2.2.3 四路残差写回

共享 Value VE:[B,S,5120]V_E:[B,S,5120] 沿四路维广播，Gate g:[B,S,4]g:[B,S,4] 沿 5120 维广播，再逐元素相乘并加回原残差：

Yb,t,c,d=Xb,t,c,d+gb,t,cVE,b,t,d,Y:[B,S,4,5120]. \boxed{ Y_{b,t,c,d} = X_{b,t,c,d} +g_{b,t,c}V_{E,b,t,d} }, \qquad Y:[B,S,4,5120].

四路使用同一份 Value，各自的 Gate 决定写入幅度；输出保持四路残差的 Shape。

官方推理实现将 Engram 表的 FP8 数据按 scale 还原为 BF16。进入 Gate 分支后，X,KE,VE,WQ,WKX,K_E,V_E,W_Q,W_K 显式转换为 FP32 参与计算；最终输出 YY 再转换回 XX 的 dtype，本配置中为 BF16。

Engram 只更新四路残差，Layer 0 传来的动态 pre_next 原样保留，与 YY 一同交给后续 Attention 侧的第一次 hc_pre。

Required Global Memory 理论下界（理想融合口径）

与 Layer 0 相同，这里把 Engram 视为一个逻辑分析单元，并采用以下假设：

  • Weight：参数和量化 scale 长期保存在 Global Memory。
  • I/O：完整输入与输出保存在 Global Memory，并分别计数。
  • Internal Activation：Eflat,F,KE,VE,D,gE_{\mathrm{flat}},F,K_E,V_E,D,g 等中间量允许通过融合、分块或工作区复用，不要求全部完整写回 Global Memory。

3. Layer 1 第一次 hc_pre 的真正变化

橙色标出的 a0,a1,a2,a3a_0,a_1,a_2,a_3 来自 Layer 0 MoE 侧 mHC 生成的动态 pre_next。Layer 0 的 Attention 入口使用固定的 [1,0,0,0][1,0,0,0]；Layer 1 不再重新创建这组固定系数，而是使用上一层传入的值：

图中的 Y0Y_0—Y3Y_3 是 2.2 中 Engram 更新后的四路残差。每一路与对应系数相乘，再沿四路相加，得到 Z:[B,S,5120]Z:[B,S,5120]。mul、add 的计算与 Layer 0 第 2.3 节 相同，图中保持绿色；橙色只强调本次汇聚的系数来源发生变化。

本层 Attention 侧的 hc_mixes 还会根据 YY 生成新的 attn_pre/post/comb。其中 post、comb 用于当前 Attention 的残差融合，attn_pre 留给紧随其后的 MoE 入口；当前 Attention 入口仍使用上一层传来的 pre_next。MoE 侧生成的 ffn_pre 则继续传给 Layer 2。Block.forward

核心结论只有三条：

  1. Layer 1 是 Layer 0 基准 Block 的第一次结构扩展。 新增 Engram，但 Attention 仍是纯 128-token SWA，MoE 与 mHC 主体不变。
  2. Engram 向四路写入共享 Value、独立 Gate。 它更新四路残差，却不改动 Layer 0 传来的动态 pre_next。
  3. 本层容量主要由条件记忆决定。 单个 Engram 带来 98.463B 逻辑参数和约 94.562 GiB 的 world_size=1 权重驻留；实际部署依赖行分片、预取或 host-memory offload，而不是把它理解成必须单卡常驻的普通线性层。
