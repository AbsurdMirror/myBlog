Layer 2：从局部注意力到压缩稀疏注意力与 MoE

1. Layer 2 总览

Layer 2 从 Layer 1 接收：

Xin:[B,S,4,5120](BF16),pnext:[B,S,4](FP32). X_{\mathrm{in}}:[B,S,4,5120]\quad\text{(BF16)}, \qquad p_{\mathrm{next}}:[B,S,4]\quad\text{(FP32)}.

其中 XinX_{\mathrm{in}} 是四路残差，pnextp_{\mathrm{next}} 是 Layer 1 的 MoE 侧 mHC 生成的下一次汇聚系数。

Layer 2 向 Layer 3 输出：

Xout:[B,S,4,5120](BF16),ffn_pre:[B,S,4](FP32). X_{\mathrm{out}}:[B,S,4,5120]\quad\text{(BF16)}, \qquad \mathrm{ffn\_pre}:[B,S,4]\quad\text{(FP32)}.

其中 XoutX_{\mathrm{out}} 是本层更新后的四路残差，ffn_pre 是本层 MoE 侧 mHC 生成的汇聚系数，作为 Layer 3 的 pre_next。

完整数据流为：

(Xin,pnext)→Layer2Block→(Xout,ffn_pre) \boxed{ (X_{\mathrm{in}},p_{\mathrm{next}}) \rightarrow \mathrm{Layer\ 2\ Block} \rightarrow (X_{\mathrm{out}},\mathrm{ffn\_pre}) }

Layer 2 依次执行 Attention 和 MoE，两侧均通过 mHC 完成四路残差的汇聚与融合。橙色 Sparse Attention 框内新增压缩、检索与 Global KV 路径，并调整 RoPE 配置，后续章节将展开说明。各步骤的作用及其与前文的关系如下；结构相同的算子仍使用本层独立参数。

步骤 Layer 2 的行为 与前文的关系
1. mHC 混合系数生成 根据输入四路残差，生成 Attention 侧混合系数 与 Layer 0 相同
2. mHC 汇聚 使用 pre_next，将输入四路残差汇聚为单路特征 与 Layer 1 相同
3. RMSNorm 对单路特征归一化，得到 Attention 输入 与 Layer 0 相同
4. Sparse Attention 接收归一化后的输入，结合局部 KV 与检索出的压缩 KV 计算注意力，输出单路特征 本文重点展开
5. mHC 残差融合 使用 Attention 侧混合系数，将 Attention 输出与四路残差融合，得到更新后的四路残差 与 Layer 0 相同
6. mHC 混合系数生成 根据更新后的四路残差，生成 MoE 侧混合系数 与 Layer 0 相同
7. mHC 汇聚 使用 attn_pre，将更新后的四路残差汇聚为单路特征 与 Layer 0 相同
8. RMSNorm 对单路特征归一化，得到 MoE 输入 与 Layer 0 相同
9. MoE FFN 接收归一化后的输入，经专家路由与前馈计算，输出单路特征 与 Layer 0 相同
10. mHC 残差融合 使用 MoE 侧混合系数，将 MoE 输出与四路残差融合，得到本层输出四路残差 与 Layer 0 相同

2. 压缩稀疏 Attention

相比于原始的全量 Attention，Layer 2 使用压缩稀疏 Attention。原始 Attention 从输入 XX 分别生成 Q、K、V；这里的 K 和 V 共用同一份表示，并分为 Local KV 和 Global KV，分别提供近期 token 的局部信息与压缩后的历史信息。

Q 和 Local KV 的生成过程与 Layer 0 基本相同，区别在于所使用的 RoPE 配置。Global KV 则走另一条路径：先由 Compressor 将每两个 token 压缩为一个 KV，再完成 RoPE 和缓存更新，供本层及指定的后续层共享。Indexer 为每个 Query 从压缩历史中选出最多 512 个位置，与最近最多 128 个 Local KV 共同组成 CwinC_{\mathrm{win}}，参与注意力计算。

下文按图中的五个模块展开：

  • 2.1 Q 与 Local KV 生成的差异：说明相比 Layer 0 的 RoPE 配置变化，以及供 Indexer 使用的 Query 中间结果。
  • 2.2 Compressor：说明两 token 压缩为一个 KV 的过程与状态更新。
  • 2.3 Indexer：说明压缩历史的评分与 Top-K 位置选择。
  • 2.4 Local 与 Global KV 及索引合并：说明 Global KV 更新，以及候选 KV 的索引组织与读取。
  • 2.5 稀疏注意力计算与输出：说明与 Layer 0 计算过程的对应关系及候选长度变化。

2.2 Compressor

同一输入 X:[B,S,5120]X:[B,S,5120] 经过双路投影，分别生成候选 KV 和逐特征压缩分数：

KV=XWKV𝖳,Z=XWZ𝖳,KV,Z:[B,S,512]. KV=XW_{KV}^{\mathsf T},\qquad Z=XW_Z^{\mathsf T}, \qquad KV,Z:[B,S,512].

将上次未配对的 KVbuf,ZbufKV_{\mathrm{buf}},Z_{\mathrm{buf}} 接到本次结果之前。图中的两个 Split / Reshape 算子分别将完整前缀按两个 token 分组，并把可能剩余的一个 token 保存为 KV′buf,Z′bufKV'_{\mathrm{buf}},Z'_{\mathrm{buf}}。本次可生成的压缩 KV 数为：

Scomp=⌊Sbuf+S2⌋,Sbuf∈{0,1}. S_{\mathrm{comp}} =\left\lfloor\frac{S_{\mathrm{buf}}+S}{2}\right\rfloor, \qquad S_{\mathrm{buf}}\in\{0,1\}.

完整分组重排为：

KV2,Z2:[B,Scomp,2,512]. KV_2,Z_2:[B,S_{\mathrm{comp}},2,512].

若本次仍未凑齐一组，则不产生压缩输出。

对每个特征，在两个 token 之间独立计算 Softmax，再加权汇聚：

A=Softmax两 token 维(Z2),A:[B,Scomp,2,512], A=\operatorname{Softmax}_{\text{两 token 维}}(Z_2), \qquad A:[B,S_{\mathrm{comp}},2,512],

KV′b,j,d=∑r=01Ab,j,r,dKV2,b,j,r,d. KV'_{b,j,d} =\sum_{r=0}^{1}A_{b,j,r,d}KV_{2,b,j,r,d}.

最后沿 512 维执行 RMSNorm，得到：

KVcomp=RMSNorm(KV′;γKV),KVcomp:[B,Scomp,512]. KV_{\mathrm{comp}} =\operatorname{RMSNorm}(KV';\gamma_{KV}), \qquad KV_{\mathrm{comp}}:[B,S_{\mathrm{comp}},512].

RMSNorm 算法沿用 Layer 0。投影、Softmax 和汇聚按 FP32 计算；汇聚结果转回 BF16 后执行 RMSNorm，输出为 BF16。此时尚未执行 RoPE，结果分别送入 Indexer 和 Global KV 分支。

2.3 Indexer

Indexer 使用 QrQ_r、KVcompKV_{\mathrm{comp}} 和 XX 三路输入，生成检索 Query、检索 Key 和 head 权重，再对压缩历史评分，为每个 Query 选择最多 512 个访问位置。

2.3.1 三路生成

未旋转的 KVcompKV_{\mathrm{comp}} 经投影、128 维 RMSNorm 和 Partial RoPE，生成本次新增的检索 Key：

KI,new=PartialRoPE(RMSNorm(KVcompWIk𝖳;γIk)),KI,new:[B,Scomp,128]. K_{I,\mathrm{new}} =\operatorname{PartialRoPE} \left(\operatorname{RMSNorm}(KV_{\mathrm{comp}}W_{Ik}^{\mathsf T};\gamma_{Ik})\right), \qquad K_{I,\mathrm{new}}:[B,S_{\mathrm{comp}},128].

将新增 Key 与旧历史接续，得到：

KI=Concat(KI,cache,KI,new),KI:[B,SG,128], K_I=\operatorname{Concat}(K_{I,\mathrm{cache}},K_{I,\mathrm{new}}), \qquad K_I:[B,S_G,128],

SG=SG,prev+Scomp. S_G=S_{G,\mathrm{prev}}+S_{\mathrm{comp}}.

图中的 Concat 表示逻辑历史接续，实现可向预分配缓存写入新增段；没有新增 Key 时，继续使用旧历史。

QrQ_r 经投影后重排为 32 个 head，每个 head 128 维，再执行 Partial RoPE：

QI=PartialRoPE(reshape(QrWIq𝖳,[B,S,32,128])). Q_I=\operatorname{PartialRoPE} \left(\operatorname{reshape}(Q_rW_{Iq}^{\mathsf T},[B,S,32,128])\right).

Query 和 Key 均旋转后 64 维，前 64 维直通。Query 使用当前 token 的绝对位置，Key 使用压缩组首个原始 token 的绝对位置。

输入 XX 经投影和缩放，生成 32 个 head 的融合权重：

wI=XWIw𝖳12832,wI:[B,S,32]. w_I=\frac{XW_{Iw}^{\mathsf T}}{\sqrt{128}\sqrt{32}}, \qquad w_I:[B,S,32].

wIw_I 不做 Softmax，直接用于后续 head 加权汇聚。

评分前，检索 Query 和 Key 执行 FP4 量化—反量化模拟，仍以 BF16 存储；图与公式省略该精度处理步骤。

2.3.2 全历史评分

每个 Query head 与全部历史 Key 做点积，经过 ReLU，再沿 head 维加权求和：

AI,b,i,h,j=∑d=0127QI,b,i,h,dKI,b,j,d,AI:[B,S,32,SG], A_{I,b,i,h,j} =\sum_{d=0}^{127}Q_{I,b,i,h,d}K_{I,b,j,d}, \qquad A_I:[B,S,32,S_G],

RI,b,i,j=∑h=031wI,b,i,hmax(AI,b,i,h,j,0),RI:[B,S,SG]. R_{I,b,i,j} =\sum_{h=0}^{31}w_{I,b,i,h}\max(A_{I,b,i,h,j},0), \qquad R_I:[B,S,S_G].

2.3.3 因果 Mask 与 Top-K 选择

设本次输入从绝对位置 p0p_0 开始。对于本次输入中的 Query ii，只有满足以下条件的压缩位置 jj 可见：

j<⌊p0+i+12⌋. j<\left\lfloor\frac{p_0+i+1}{2}\right\rfloor.

其余评分设为 −∞-\infty。从 Mask 后的评分中选择 Top-K，再按压缩位置升序排列：

k=min(512,SG),Isorted=SortAscending(TopKIndicesk(R′I)). k=\min(512,S_G), \qquad I_{\mathrm{sorted}} =\operatorname{SortAscending} \left(\operatorname{TopKIndices}_k(R'_I)\right).

最后，有效索引加上 Local 数据源长度 SLS_L，无效索引设为 −1-1，得到交给 2.4 的访问索引：

IG={Isorted+SL,有效位置,−1,无效位置,IG:[B,S,k](INT32). I_G= \begin{cases} I_{\mathrm{sorted}}+S_L,&\text{有效位置},\\ -1,&\text{无效位置}, \end{cases} \qquad I_G:[B,S,k]\quad\text{(INT32)}.

早期 Query 的可见压缩历史可能不足 kk，因此实际有效索引数可以少于槽数。

2.4 Local 与 Global KV 及索引合并

本节更新 Global KV 历史，将它与 Local KV 拼接为统一数据源，再合并两路访问索引，读取每个 Query 对应的候选 KV。

2.4.1 Global KV 更新

未旋转的 KVcompKV_{\mathrm{comp}} 先执行 Partial RoPE：前 448 维直通，后 64 维按压缩组首个原始 token 的位置旋转：

KVrot=PartialRoPE(KVcomp),KVrot:[B,Scomp,512]. KV_{\mathrm{rot}} =\operatorname{PartialRoPE}(KV_{\mathrm{comp}}), \qquad KV_{\mathrm{rot}}:[B,S_{\mathrm{comp}},512].

随后按每 16 个通道一组执行 FP4 量化模拟，结果仍以 BF16 保存，得到本次新增的 KVG,newKV_{G,\mathrm{new}}。

将新增部分写入 Global KV 缓存，与旧历史共同形成当前有效历史：

KVG:[B,SG,512],SG=SG,prev+Scomp. KV_G:[B,S_G,512], \qquad S_G=S_{G,\mathrm{prev}}+S_{\mathrm{comp}}.

图中的 Concat / Cache Update 表示逻辑历史接续，可在预分配缓存中原地更新；没有新增压缩 KV 时，继续使用旧历史。

2.4.2 数据源与访问索引合并

图中右侧将 Local KV 放在前面、Global KV 放在后面，沿序列维拼接：

KV=Concat(KVL,KVG;dim=1),KV:[B,SL+SG,512]. KV=\operatorname{Concat}(KV_L,KV_G;\mathrm{dim}=1), \qquad KV:[B,S_L+S_G,512].

左侧根据 Query 的绝对位置、128-token 因果窗口和 Local 缓存布局，生成局部访问索引：

IL:[B,S,kL],kL≤128. I_L:[B,S,k_L],\qquad k_L\le128.

Global 索引 IGI_G 来自 2.3，已经完成 Top-K 选择及 SLS_L 偏移。将它与 ILI_L 沿最后一维直接拼接：

I=Concat(IL,IG;dim=−1),I:[B,S,K], I=\operatorname{Concat}(I_L,I_G;\mathrm{dim}=-1), \qquad I:[B,S,K],

K=kL+k≤640,k=min(512,SG). K=k_L+k\le640,\qquad k=\min(512,S_G).

统一数据源 KVKV 按 batch 共享，访问索引 II 则按 Query 独立组织。两路索引中的无效槽均保留为 −1-1。

2.4.3 按有效索引 Gather

根据统一索引生成有效性 Mask，并读取对应的 KV：

Maskb,i,t=(Ib,i,t≥0), \mathrm{Mask}_{b,i,t}=(I_{b,i,t}\ge0),

Cwin,b,i,t,:=KVb,Ib,i,t,:,Ib,i,t≥0. C_{\mathrm{win},b,i,t,:} =KV_{b,I_{b,i,t},:}, \qquad I_{b,i,t}\ge0.

逻辑上得到：

Cwin:[B,S,K,512],Mask:[B,S,K]. C_{\mathrm{win}}:[B,S,K,512], \qquad \mathrm{Mask}:[B,S,K].

无效槽由 Mask 屏蔽。每个 Query 最多使用 128 个 Local KV 和 512 个 Global KV，候选长度 KK 对应 2.5 中的 SwinS_{\mathrm{win}}。

图中将 Gather 单独展开；官方参考实现把这一步融合在 sparse_attn 内核中，按统一索引分块读取 KV，直接参与后续注意力计算。

2.5 稀疏注意力计算与输出

本步骤与 Layer 0 第 4.2 节 相比，唯一变化是输入 CwinC_{\mathrm{win}} 的 SwinS_{\mathrm{win}} 维度：每个 Query 对应的候选 KV 数由最多 128 增加到最多 640，特征维度仍为 512。除候选长度变化所对应的维度外，其余张量的 shape 和全部计算算法均保持一致，因此直接复用上图及原章节的推导。

图中的 128-token SWA mask 对应 Local 分支；Global 候选的因果有效性由 2.3 的筛选与 2.4 的 Mask 保证。

注意力结果随后按本层 RoPE 配置执行逆旋转，并经两级分组输出投影得到 O:[B,S,5120]O:[B,S,5120]，结构沿用 Layer 0 第 4.3 节。

4.5 输出与跨层状态

Layer 2 向 Layer 3 输出四路残差 Xout:[B,S,4,5120]X_{\mathrm{out}}:[B,S,4,5120]（BF16），并将 MoE 侧的 ffn_pre:[B,S,4]（FP32）作为 Layer 3 的 pre_next。
